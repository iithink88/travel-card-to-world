# 文章原版提示词（概念参考 · 完整存档）

> 来源：公众号「这事AI能做」，2026-09-10，《我只用了一条提示词，就让旅行照片从卡片里长出来》
>
> 用法提醒：**不要单独整段发给图生图模型**，实测会输出宝丽来白边 + 照片平印。
> 把它当条款素材库，配合 `prompt-master.md` §1 的三段分区版使用。

---

```
请先仔细分析我上传的图片，再开始生成。

基于上传图片，创作一张 4:5 竖版、超现实电影感、高级编辑旅行摄影作品。

【一、先自动判断上传图片类型】

请先判断上传图片属于：
A. 风景 / 城市 / 建筑照片
B. 人物 / 肖像 / 旅行人物照片
C. 人物 + 明确环境照片

然后按照对应规则生成。

如果是风景 / 城市 / 建筑照片：
上传图片是场景内容的唯一视觉依据。准确识别原图中真实存在的主要建筑、天际线、水体、岛屿、山体、道路、桥梁、摩天轮、植被、岸线及其真实的比例、位置和空间关系。
禁止根据城市名、国家名、文化印象、旅游常识或模型已有知识，自行加入原图中不存在的地标或文化符号。
核心原则：不要表现"这个城市通常长什么样"，只表现"用户上传的这张照片里实际有什么"。
如果原图是现代城市，就保持现代城市。
原图没有古建筑，就禁止添加古建筑、寺庙、古塔、亭台楼阁、传统民居等元素。

如果是人物照片：
上传人物是人物身份的唯一参考。严格保持脸型、五官比例、眼睛、鼻子、嘴巴、发际线、发型、年龄感、肤色、表情、气质和身体比例。
不要换脸，不要网红化，不要自动瘦脸、放大眼睛、缩鼻、丰唇、年轻化或过度磨皮。
人物原始背景不强制保留，可以根据旅行主题替换为真实、自然、高级的城市、海边、湖边、山景、街道、建筑或其他旅行环境。

如果图片同时有人物和明确环境：
人物身份必须严格保留；
环境优先参考原图，但可以根据最终构图适度调整、扩展或替换。

【二、不要机械复制整张原图】

不要把上传照片完整缩小后直接塞进卡片里。
上传图片只是内容来源，不是必须一比一复制的构图模板。
请先判断原图中的真正视觉主体，再重新组织构图。
主动删减无意义或占比过大的前景、天空、水面、道路、空地等区域。
优先保留最重要的 2–5 个主体元素。
次要环境只用于建立空间，不要机械保留。
最终微缩世界应该是对原图的视觉提炼和重新构图，而不是整张照片的缩略版。

【三、核心主体必须位于画面正中央】

无论原始照片中的主体位于什么位置，生成时都允许重新组织构图。
必须把真正的核心主体重新安排到画面中央。
如果是城市 / 建筑照片：最高、最重要、最具识别度的主体建筑必须位于整体视觉中央。
如果是人物照片：人物本身或人物与卡片形成的组合必须处在核心视觉区域。
整个"手 + 卡片 + 卡片上升起的主体世界"必须位于画面中央。
如果需要在"展示更多背景"和"让主体居中"之间做选择，始终优先主体居中，并主动裁减背景。
视觉优先级必须是：
第一眼：卡片上的人物 / 核心建筑 / 立体世界
第二眼：卡片与手
第三眼：背景环境

【四、核心空间创意：卡片正在变成真实世界】

最终画面不是"四边完整的卡片 + 卡片内部摆着一个小模型"。
而是"一张真实卡片正在向现实世界连续展开"。
一只真实自然的人手单手握住一张极简、高级、有真实纸张纹理的旅行卡片。
卡片靠近镜头的前缘和近端边缘必须清晰存在。
但越向卡片远端：纸张感越弱，真实空间感越强。
形成连续转化：
真实纸张前缘 → 卡片表面的二维图像 → 逐渐产生真实空间深度 → 水面 / 沙滩 / 道路 / 草地 / 地形 → 人物 / 植物 / 建筑从平面真实升起 → 卡片远端边缘逐渐消失 → 无缝连接到后方真实环境。
最远端不要出现清晰完整的纸张边界。

【五、卡片远端必须和背景真正接在一起】

卡片与真实背景必须共享同一条透视线、同一个地平线、同一个光线方向、同一个色温、同一个空气环境和同一个世界。
海边：卡片中的沙滩直接延伸成背景沙滩，海水直接连续进入背景海洋。
湖泊：卡片上的湖水直接过渡成背景湖面。
城市：卡片中的道路、水面、建筑或天际线沿同一透视继续延伸进入真实环境。
禁止卡片和背景形成两个独立世界。

【六、必须是真正的三维立体世界】

卡片中的世界不能只是平面印刷照片，也不能只是轻浮雕。
必须有明确的 XYZ 三维空间。
需要表现前景、中景、后景，以及真实的高低差、体积、厚度、空间纵深、遮挡关系、接触阴影、环境光和自然反射。
人物、建筑、树木、岛屿、沙堡、礁石或其他主体要真正从卡片平面中立起来。
不要玩具模型感。不要建筑沙盘感。不要纸雕感。不要纸片立牌感。

【七、人物照片的特殊处理】

如果上传图片中有人物：
人物必须作为真实三维主体存在，而不是被印在卡片上。
人物下半身或接触部位可以处于卡片生成的空间中，上半身、头部、头发、手臂可以自然进入真实背景的空气空间。
形成"人物真实存在于一张悬浮卡片打开的世界里"的视觉错觉。
人物本身仍然遵循真实重力和接触逻辑。

【八、背景必须明显降权】

背景只能提供旅行现场感、地点感、真实空间感和氛围感。
背景绝对不能抢主体。
背景必须比卡片和卡片上的立体世界更虚、更柔、更低对比、更低锐度、更低细节密度。
使用明显但自然的浅景深。
避免复杂云层、夸张日落、强烈太阳光束、大面积高亮、戏剧化天空、过度 HDR 和复杂背景细节。
背景应安静地衬托主体。

【九、整体调色可以优化】

不要求完全复制原照片的原始颜色。
可以在忠于原场景的前提下进行高级电影感调色。
允许轻微提亮主体、优化明暗层次、调整白平衡、降低杂乱色彩、增强主体与背景层次、增加空气感。
整体采用低至中等饱和度、柔和高光、干净阴影、自然暖冷关系和克制电影色调。
不要过度饱和、过度暖黄、强烈 HDR 或廉价旅游宣传片调色。

【十、卡片设计】

卡片采用高级、极简、现代编辑设计。
使用真实高克重纸张、哑光艺术纸、棉纸或细腻纸纤维质感。
颜色以象牙白、米白、浅灰白和低饱和自然色为主。
卡片下方保留适量干净留白。
加入：[DESTINATION NAME]
采用高级、极简、克制的英文大写排版。
文字不能抢过主体。

【十一、摄影质感】

整体必须像真实摄影，而不是数字艺术。
使用电影感自然光、真实皮肤纹理、真实手部结构、真实纸张、真实建筑、水面、植物、阴影、自然反射、浅景深、空气透视和真实镜头光学感。
整体气质高级、极简、安静、通透、有留白、有旅行感，并带有轻微超现实感。
超现实只发生在"卡片正在变成一个真实世界"这件事上。

【严格禁止】

禁止把整张原图完整复制进卡片。
禁止保留过大的无意义水面、天空、道路或沙滩。
禁止核心建筑或人物偏离画面中央。
禁止背景比主体更显眼。
禁止普通风景空镜。
禁止航拍式城市远景。
禁止卡片压在画面底部。
禁止四边完整的卡片容器效果。
禁止卡片远端明显白边。
禁止卡片和背景形成两个世界。
禁止平面照片直接印在卡片上。
禁止人物被印在卡片上。
禁止纸片人物。
禁止纸雕。
禁止玩具模型。
禁止建筑沙盘。
禁止塑料材质。
禁止插画。
禁止卡通。
禁止动漫。
禁止明显 CGI。
禁止明显 3D 渲染感。
禁止廉价拼贴。
禁止旅游宣传册风格。

【最终效果】

最终成片必须让人第一眼看到位于画面中央的核心人物 / 核心建筑，以及它所在的卡片世界。
上传照片中的内容经过主动提炼和重新构图，而不是被完整缩小复制。
无意义的大面积水面、天空或前景被压缩。
真正有辨识度的主体被放大、居中并立体化。
卡片近端仍然是真实纸张，中部逐渐成为三维世界，远端彻底融入真实背景。
背景柔和、安静、略虚化，只负责衬托主体。
最终形成：
近处是一张被手握住的旅行卡片，
中央是从卡片中升起的真实立体世界，
远处这个世界已经自然延伸进现实。
不是"把一个世界放进卡片里"，
而是："这张卡片正在变成这个世界"。
```

## 原文的核心方法论（六条）

1. **先判断是风景照还是人物照**。风景锁场景内容，人物锁人物身份，不要一套规则硬套。
2. **不要机械复制原图构图**。上传照片是内容依据，不是最终版式模板。删掉过多的水面、天空、空地和次要环境，把真正的主体重新放大、居中。
3. **卡片不是容器，而是在变成世界**。近端保留真实纸张，中间从二维转三维，远端边缘消失，最后和背景接在一起。
4. **人物和建筑必须真的"立起来"**。不是印刷图、不是轻浮雕、不是纸片立牌。要有真实的前后空间、遮挡、体积、接触阴影和环境光。
5. **背景永远不能抢主体**。背景只负责地点感和氛围。
6. **忠实内容，不忠实构图** —— 最反直觉、也最容易做错的一条。
