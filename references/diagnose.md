# 看片 · 判断 · 修图

## 一、先判类型（决定后面所有规则）

| 类型 | 判定条件 | 优先级 |
|---|---|---|
| **A 风景/城市/建筑** | 画面无人，或人只是远处小比例点缀 | 锁场景内容 |
| **B 人物/肖像** | 人物占画面 1/4 以上且是视觉中心，背景可虚可简 | 锁人物身份 |
| **C 人物+明确环境** | 人物清晰且背景本身也是有效内容 | 双锁，人物优先 |

边界处理：

- **人很多（街头/景区人潮）**：按 A 处理，但选 1–2 个最清晰的人物作为「可立起来的主体」，其余虚化。不要试图让 20 个人都立起来。
- **全景/超广角/航拍**：最容易失败。必须先裁出局部主体再生成——航拍视角下没有「地平线」，卡片无法接进背景。处理办法：在提示词里把视角改成地面人眼视角，只保留原图的地点特征。
- **室内**：可以接，但介质要用地面/桌面/地板的连续面。墙面的透视必须一致，否则立刻崩。
- **动物/宠物**：按 B 处理，锁毛色、体型、脸型。

## 二、主体提炼（这一步决定成片档次）

### 法则

> 忠实原图的**内容**，不忠实原图的**构图**。

一张旅行照里通常有大量「填充物」——天空、水面、马路、沙滩、空地。它们在原图里合理，但塞进卡片后会把真正的主体挤小。所以必须做**减法**。

### 取舍清单

| 保留（成为立体主体） | 压缩或删除 |
|---|---|
| 最高/最具识别度的建筑（1 座为主） | 超过画面 1/3 的天空 |
| 有轮廓特征的自然物（礁石、孤树、山脊、浪线） | 大面积无内容水面、空地、马路 |
| 人物/动物（1–2 个） | 杂乱前景（电线、垃圾桶、路人背影、停靠车辆） |
| 有方向性的线（岸线、道路、桥、栈桥、台阶） | 重复的次要建筑群 |
| 一个「质感锚点」（沙堡、贝壳、灯笼、招牌、石阶） | 文字招牌、广告、车牌（易出乱码） |

### 数量

**2–5 个。** 少于 2 个 → 画面空、不像世界；多于 5 个 → 挤成一团、全糊。

### 写法

用「名称 + 数量 + 相对位置 + 朝向」写，越具体越稳：

- 差：`海滩、大海、树`
- 好：`一道弧形浪线横贯前景沙滩，中景青绿海面，左后方一小片椰林与三栋浅色低层建筑`

## 三、介质连续性（卡片怎么接进背景）

卡片必须借一个**连续介质**长出去，否则一定会出现「两个世界」。选介质比调色更重要。

| 原图场景 | 首选介质 | 接法 |
|---|---|---|
| 海边 | 沙滩 / 浪线 | 卡片里的沙面 → 背景沙面；浪线沿同一弧线延伸 |
| 湖泊 | 湖面 | 卡片水面直接过渡为背景湖面，共享同一水平倒影线 |
| 河流/运河 | 水面 + 岸线 | 水流方向贯穿，两岸透视同一灭点 |
| 城市 | 道路 / 广场地面 / 水面 | 路沿同一透视线延伸；楼体阴影方向一致 |
| 山景 | 山脊线 / 草坡 | 山脊轮廓在卡边处连续，不改高度 |
| 森林/草地 | 草地 / 落叶层 | 草的密度与光斑延续到背景 |
| 沙漠 | 沙纹 | 沙纹走向连续，不留接缝 |
| 雪景 | 雪面 | 雪的颗粒与蓝白冷暖统一 |
| 花田 | 花行 | 花行的透视行距延续 |
| 街巷 | 石板路 / 墙脚线 | 石板缝方向与砖缝高度一致 |

**没有明显介质时**（如建筑立面特写、室内白墙）：改用「地面 + 人物/建筑脚部接地阴影」作为接口，并加大背景虚化。

## 四、头号顽疾：模型死活要画宝丽来

这是实测中最顽固的问题。同一张原图连试三次：

| 版本 | 做法 | 结果 |
|---|---|---|
| v1 | 文章原版十一节结构 | ❌ 四边完整宝丽来 + 照片平印 |
| v2 | 加「卡片斜向延伸、只有三条边」+ 一大堆禁止 | ❌ 仍是宝丽来白边 |
| v3 | 三段像素分区 + **软纸弯曲** + `input_fidelity: low` | ✅ 上段全是真实海岸，纸在沙滩里融化 |

**根因**：「手持一张照片」这个画面，在模型训练数据里几乎全是宝丽来。加禁止词没用，因为你要的是同一类物体的**反常规形态**。

**三个真正管用的动作**（按效力排序）：

1. **换材质，不加禁止**。把「硬挺卡片」改成「柔软、轻薄的印刷纸，被手指从下方捻住，向画面上方弯曲伸展，中部微微下弯，远端没有边」。相框画不出弯曲的软纸，物理上就排除了。
2. **给坐标，不给形容词**。「远端逐渐消失」→「画面顶部 35% 这一段里不能出现任何纸张、任何白色边框、任何纸张转角」。
3. **加一句自检**。末尾写「如果画面上半部分能看到任何一条纸边，就是失败」。

## 五、失败修法表（只改对应那一段，别整段重写）

| 现象 | 根因 | 只改这里 |
|---|---|---|
| 四边完整 / 宝丽来白边 | 硬卡纸先验 | 见上方 §四，换材质 + 给坐标 + 加自检，三招一起上 |
| 照片被整张缩进卡片 | 第二节失效 | 点名写出要删掉的天空/水面比例，明确「压缩为原来的三分之一」 |
| 建筑偏左/偏小 | 第三节失效 | 加「主体建筑必须占据画面中央纵向 60% 以上的视觉高度」 |
| 背景太清楚，两个世界 | 第八节失效 | 加「背景虚化程度至少为主体景深的 2 倍，对比度明显低于主体」 |
| 出现原图没有的古建/地标 | 常识脑补 | 在 §A 后追加「原图没有的元素一律禁止新增，宁缺勿加」 |
| 像玩具模型 / 沙盘 | 第六节失效 | 加「真实人眼视角，非微缩摄影，非移轴，非 tilt-shift」 |
| 人物脸变了 | 锁身份不足 | `input_fidelity` 提到 `high`，并在提示词里逐项列出五官要求 |
| 人物像贴纸浮在卡上 | 第七节失效 | 加「人物头部与手臂越过卡片空间进入背景空气，人物在背景上投下真实阴影」 |
| 卡片上的英文乱码 | AI 文字弱点 | 改短地名（≤3 词、不用生僻词），或直接去掉文字要求，后期不加字 |
| 整体像旅游海报/CGI | 第十一节失效 | 加「真实相机拍摄，50mm 定焦，f/2.0，自然光，无 HDR」 |
| **成片比原图更灰、更寡淡** | 原图的平淡阴天调被完整继承 | 见下方 §五之二 |
| 纸面主体像褪色印刷，不够鼓 | 只说了「立体」，没给物理细节 | 加「纸面在主体根部产生凹陷和阴影」「荷花比叶片高出 15–25cm，在后方叶片上投下真实阴影」 |

## 五之二、原图本身就是灰平调怎么办

阴天、雾霾、手机直出的平淡照片，模型会**忠实继承那个灰度**，生成出来往往比原图还寡淡。这时"忠于原场景"要让位于"高级感"。

三件事一起做：

1. **逐项规定颜色**，别指望模型自己提亮。
   - 天空：「柔和通透的浅银灰带一点暖意，有微弱云层层次，不是平坦的灰白板」
   - 主体：「干净通透的翠绿与黄绿，有明确明暗分层和边缘高光，不是发脏的黄绿」
2. **明确否定**：「不要发灰、不要发黄、不要寡淡」「禁止继承原图的阴天感」。
3. **把灰度写进自检**：「如果成片比原图更灰更淡，也是失败」。

实测：同一张阴天荷塘照，加上这三条后第二版明暗层次和通透度明显提升，仍是写实风，没有变成过度艳俗的糖水片。

## 六、九条自检（出图后逐条打勾）

1. ☐ 能明确指出卡片远端边缘在哪吗？——**能指出 = 失败**
2. ☐ 核心主体在画面中央纵向区域内吗？
3. ☐ 主体有明确体积、厚度、遮挡、接地阴影吗？
4. ☐ 第一眼看到的是主体，而不是背景或整张卡片？
5. ☐ 背景明显更虚、更低对比吗？
6. ☐ 卡片远端和背景是同一条地平线/透视线/光向/色温吗？
7. ☐ 有没有出现原图不存在的地标或文化符号？
8. ☐ 有人物时，脸还是同一个人吗？
9. ☐ 能不能删掉任何一处「无意义的大面积天空/水面/空地」让主体更大？

九条全过 → 交付。第 1、2、3 条任一不过 → 必须重出。
