# 提示词母版 · Travel Card to World

> 两个版本：**§1 三段分区版**（本机实测有效，主推）、**§2 文章原版**（概念参考）。
> 实测结论：原版提示词单独用，图生图模型有极高概率输出「宝丽来白边 + 照片平印」的失败结果。原因和破解法见 §3。

## §1 三段分区版（主推 · 实测有效）

### 槽位对照

| 槽位 | 填什么 |
|---|---|
| `{{ONE_LINER}}` | 一句话核心：照片正在从一张软纸变成真实的 `{{场景}}` |
| `{{TYPE_RULE}}` | 类型规则一句话（见 §1.3） |
| `{{BAND_TOP}}` | 上段（顶 35%）里只能有什么 —— 真实世界的那部分内容 |
| `{{BAND_MID}}` | 中段（35%–65%）过渡区发生了什么 —— 纸边怎么消失、什么开始立体化 |
| `{{BAND_BOTTOM}}` | 下段（65%–100%）里只有什么 —— 手 + 纸的近端 + 文字 |
| `{{PAPER_NEAR}}` | 纸的近端细节：毛边、纤维、微微翘起、厚度 |
| `{{MEDIUM}}` | 纸变成的那种真实介质：沙滩 / 海面 / 草地 / 路面 |
| `{{SUBJECTS}}` | 2–5 个主体，带数量与相对位置 |
| `{{MEDIUM_LINK}}` | 介质连续性一句话 |
| `{{CARD_TITLE}}` | 卡片上的英文大写地名，≤3 词 |
| `{{COLOR_RULE}}` | 色彩规定。**原图灰平时必填**，逐项指定天空与主体的颜色层次，并写明「不要发灰、不要寡淡」。正常照片可写「忠于原场景的高级电影感调色」 |

### 完整提示词（复制这段，替换槽位）

```
请仔细分析我上传的图片，然后生成一张 4:5 竖版、超现实电影感的高级旅行摄影作品。

【核心一句话】{{ONE_LINER}}

【类型规则】{{TYPE_RULE}}

【画面上中下三段，必须严格遵守】
上段（画面顶部 35%）：100% 是真实世界。{{BAND_TOP}}。这一整段里不能出现任何纸张、任何白色边框、任何卡片轮廓、任何相框阴影。
中段（画面 35% 至 65%）：过渡区。{{BAND_MID}}。纸面图像与真实景物在这里融合成同一个空间，没有分界。
下段（画面 65% 至 100%）：只有三样东西——一只真实的手、一张柔软的米白色薄纸的近端、纸上极简的小字 {{CARD_TITLE}}。{{PAPER_NEAR}}

【纸张形态】
这不是一张硬挺的卡片，不是宝丽来，不是拍立得，不是相框，不是一张被人举起来展示的照片。
它是一张柔软、轻薄的印刷纸，被手指从下方轻轻捻住，向画面上方弯曲伸展。纸张中部微微下弯，远端没有边——纸的边缘在弯曲处就消失了，图像直接变成真实的{{MEDIUM}}。

【内容】
只表现我上传的这张照片里真实存在的东西：{{SUBJECTS}}。
禁止添加原图没有的地标、古建、文化符号。禁止把整张原图缩进纸里；原图里占比过大的天空、水面、空地压缩到几乎没有，主体放大并居中。
{{MEDIUM_LINK}}
主体必须真正三维化：有厚度、体积、前后遮挡、接地阴影和环境光。真实人眼视角，非微缩摄影，非移轴。不是平面印刷，不是轻浮雕，不是纸片立牌。

【质感】
真实摄影，50mm 定焦，f/2.0，自然光，无 HDR。真实掌纹、纸纤维、水面的反光、浅景深、空气透视。
背景更虚、更柔、更低对比，细节密度低于主体的三分之一。低至中等饱和度，柔和高光，干净阴影，克制的电影色调。

【色彩】{{COLOR_RULE}}

【禁止】
禁止白色相框。禁止宝丽来白边。禁止四边完整。禁止在画面上半部分看到任何纸边、纸张转角或相框阴影。禁止硬挺卡片。禁止把照片平印在纸上。禁止纸雕、玩具模型、建筑沙盘、塑料材质、CGI 感、插画、卡通、动漫、廉价拼贴、旅游宣传册风格。禁止纸垂直立在镜头前展示。禁止卡片和背景形成两个世界。

【自检】①成片里如果画面上半部分能看到任何一条纸边、任何一点白色边框、任何纸张转角，就是失败。②如果成片比原图更灰、更淡、更寡淡，也是失败。
```

### §1.3 `{{TYPE_RULE}}` 三选一

**A 风景/城市/建筑**
```
上传图是风景/城市/建筑照。上传图是场景内容的唯一依据，只表现这张照片里实际存在的东西；禁止根据地名、国家或常识新增原图没有的地标与文化符号。原图是现代城市就保持现代城市。
```

**B 人物/肖像**
```
上传图是人物照。上传人物是身份的唯一参考：严格保持脸型、五官比例、眼距、鼻形、唇形、发际线、发型、年龄感、肤色、表情、气质和身体比例。不要换脸、不要网红化、不要瘦脸放大眼缩鼻丰唇、不要年轻化或过度磨皮。人物背景可以替换为符合主题的真实旅行环境。人物身份严格保留，环境为画面服务。
```

**C 人物 + 明确环境**
```
上传图是人物加环境照。人物身份必须严格保留（同上）；环境优先参考原图，可适度调整、扩展或替换；人物与环境的相对关系（谁在前、朝向、光线方向）必须真实可信。
```

## §2 文章原版（概念参考，不建议单独使用）

原版是一份非常好的**概念说明书**，十一条结构把创意讲得很透，适合讲解、存档、喂给理解力强的模型。但它有两个实测问题：

1. 太长。核心创意（卡片远端消失）被十一节稀释，模型抓不住重点。
2. 用了「卡片 / 相框 / 展示」这套词汇，直接触发模型对宝丽来的强先验。

保存的完整原版见 `prompt-master-article.md`。需要时把它当**素材库**用，取其中的条款往 §1 里补，而不是整段发。

## §3 为什么三段分区版有效（核心技法，别丢）

三次实测，同一张海边原图：

| 版本 | 关键做法 | 结果 |
|---|---|---|
| v1 | 文章原版结构 + 「远端逐渐消失」 | ❌ 四边完整宝丽来，照片平印 |
| v2 | 加「卡片斜向延伸、只有三条边」+ 大量禁止 | ❌ 仍是宝丽来白边 |
| v3 | **三段像素级分区 + 软纸弯曲 + `input_fidelity: low`** | ✅ 上段全是真实海岸，纸在沙滩里融化 |

四条可复用的经验：

**① 用「像素分区」代替「形容词」。**
「远端逐渐消失」是形容词，模型自由发挥。改成「画面顶部 35% 里不能出现任何纸边」是坐标，模型只能照做。凡是想控制空间，就给百分比。

**② 把硬卡纸改成软薄纸。**
宝丽来的本质是**硬挺的平面卡纸 + 白边框**。一旦描述成「柔软轻薄的纸、被手指捻住、向画面上方弯曲、中部下弯」，物理上就画不出相框了。这是最有效的一招——不是加禁止，是换材质。

**③ `input_fidelity` 风景用 `low`，人物用 `high`。**
`medium` 会让模型倾向于保留原图的平面结构，反而更容易把它整张塞进卡片。风景照要的是「重新构图」，`low` 更放手；人物照要的是「脸不变」，必须 `high`。

**④ 加一句自检。**
末尾写「如果画面上半部分能看到任何一条纸边，就是失败」，模型会自我复核，实测能明显减少四边完整的输出。
